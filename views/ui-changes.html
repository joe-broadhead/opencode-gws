Changes from agent UIs

An agent can put a button in a UI that updates cells in one of your Google Sheets. Each time you press it, Jelly asks you first and shows the plugin's own preview of every cell it writes. Values are stored exactly as written, never as formulas.

It is off unless the plugin's uiActions option lists sheets.spreadsheets.values.update. With access set to read-only, nothing changes.

Agents make the same change with gws_plan and gws_write. This page only explains the action; it never runs it.
